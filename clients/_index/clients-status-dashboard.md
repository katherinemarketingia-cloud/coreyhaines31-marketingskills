# Clients Status Dashboard

Panel operativo para seguimiento multi-cliente sin mezclar contexto.

## Reglas de uso

- Un cliente por slug único (`kebab-case`).
- Todo entregable debe vivir en `clients/<client_slug>/...`.
- Todo archivo operativo debe incluir `Cliente` y `Periodo`.
