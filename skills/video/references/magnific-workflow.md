# Magnific Visual Workflow Framework

Use this reference when the video skill needs to support a broader visual production system for static pieces, carousels, covers, screenshots, mockups, realistic backgrounds, and visual support for reels.

This is a **manual operating framework** for using ChatGPT, Magnific, Canva, and a video editor together. It does not assume native API access, automatic publishing, WhatsApp automation, or repository-level integration with Magnific or Canva.

---

## A. Purpose

This framework helps you turn a campaign message into a consistent visual asset system. Use it to define the creative direction, produce or improve base imagery, compose final editable assets, and adapt those assets across organic and paid formats.

It helps create:

- Static feed pieces and one-off campaign graphics
- Carousel covers and multi-slide visual systems
- Paid ad images and creative variants
- Improved website screenshots and UI mockups
- Realistic photographic backgrounds for branded compositions
- Reel covers, intro frames, end cards, and visual support frames
- Reference frames for image-to-video or editor-based motion work

## B. Use Cases

- **Static posts:** editorial statements, offer posts, testimonials, launches, reminders.
- **Carousels:** educational breakdowns, before/after narratives, objection handling, campaign sequences.
- **Covers:** reel covers, YouTube thumbnails, carousel first slides, webinar or event covers.
- **Ads:** image ads, lead magnet ads, service offer ads, retargeting visuals, variant testing.
- **Website screenshots/mockups:** landing page screenshots, dashboard screens, app mockups, page previews.
- **Reel support:** background plates, section cards, visual metaphors, mockup frames, thumbnail concepts.

## C. What This Framework Does Not Do

- It does **not** automatically connect to WhatsApp, Canva, Magnific, or any publishing platform.
- It does **not** replace final manual editing, layout judgment, or brand approval.
- It does **not** guarantee native integration with Magnific or Canva unless the repo contains a verified integration and the user has configured access.
- It does **not** replace real client assets such as original photography, logos, screenshots, filmed footage, testimonials, or product captures.
- It does **not** ask AI image tools to generate reliable readable text. Add final text in Canva, Hyperframes, Remotion, CapCut, or another editor.

## D. Minimum Required Inputs

Gather these before creating the visual workflow:

| Input | Why It Matters |
|-------|----------------|
| **Client** | Determines brand context, audience expectations, and visual boundaries. |
| **Offer** | Anchors the creative around the commercial or content objective. |
| **Audience** | Shapes visual maturity, tone, proof, and emotional framing. |
| **Piece objective** | Clarifies whether the asset should educate, convert, announce, nurture, or retarget. |
| **Format** | Defines size, density, pacing, and export requirements. |
| **Base copy** | Provides hook, headline, CTA, and slide structure. |
| **Visual references** | Shows what “premium,” “editorial,” “warm,” or “technical” means for this client. |
| **Palette** | Keeps generated and composed assets aligned with brand colors. |
| **Typography** | Defines headline and support text hierarchy in final editable designs. |
| **Real photos/screenshots** | Prevents generic AI output and increases trust. Use real assets when available. |

## E. Step-by-Step Workflow

1. **Define the piece objective.** Decide whether the asset is for awareness, education, conversion, retargeting, launch support, or content packaging.
2. **Define the message and hook.** Write the headline, supporting line, CTA, and any carousel slide beats before generating visuals.
3. **Define the visual style.** Specify mood, composition, lighting, color direction, density, and what to avoid.
4. **Gather real assets.** Collect logos, screenshots, website captures, product mockups, founder/team photos, location photos, customer proof, or campaign references.
5. **Generate or improve the base visual.** Use ChatGPT to write prompts for a background, mockup, screenshot enhancement, or editorial image direction.
6. **Use Magnific when appropriate.** Run the selected screenshot, mockup, generated image, or photographic base through Magnific manually when it needs detail, realism, depth, or polished texture.
7. **Build the final composition.** Use Canva or another design tool for text, overlays, logo placement, hierarchy, spacing, brand typography, and export versions.
8. **Export versions.** Prepare platform-specific sizes such as 1080x1350, 1080x1080, 1080x1920, 1200x628, or client-specific specs.
9. **Review brand consistency.** Check palette, typography, contrast, realism, logo usage, tone, and whether the piece feels like the client.
10. **Adapt for campaign or organic.** Campaign versions need sharper offer clarity and CTA. Organic versions can be more editorial, educational, or narrative.

## F. Specific Use of Magnific

### When Magnific Is Useful

Use Magnific when an image already has a strong concept but needs more production value:

- Website screenshots that feel flat and need a polished presentation context
- Mockups that need more realistic lighting, texture, or depth
- Photographic backgrounds that need more atmosphere or resolution
- AI-generated images that are close but still feel unfinished
- Reel cover backgrounds that need a premium editorial look before text is added
- Campaign visuals where detail and realism can increase perceived quality

### When Not to Use Magnific

Avoid Magnific when:

- The input is off-brand, poorly composed, or based on the wrong concept.
- The image contains important tiny text that must remain exact.
- The asset must preserve legal, medical, financial, or compliance-sensitive details exactly.
- The main issue is layout, hierarchy, or copy. Fix those in Canva or the editor instead.
- You do not have permission to alter the source asset.

### Image Types Magnific Usually Helps Most

- High-quality photos with clear subjects and room for detail
- Realistic AI backgrounds that need texture and depth
- Website screenshots placed inside device or browser mockups
- Product or service visuals that need a more premium presentation
- Editorial-style backgrounds where lighting and composition matter

### Screenshots and Website Mockups

- Capture the cleanest real screenshot available.
- Remove sensitive information before enhancement.
- Place the screenshot in a browser frame or device mockup before enhancement if the final piece needs that context.
- Do not rely on enhancement to preserve small body text. Add key copy separately in Canva.
- After Magnific, verify that logos, UI elements, numbers, and visible claims were not distorted.

### Photographic Backgrounds

- Use real client photos first when available.
- If generating a background, keep it plausible for the client’s market and audience.
- Avoid overly perfect rooms, plastic skin, impossible lighting, and obvious stock-photo poses.
- Leave negative space for text overlays.
- Use color grading that supports the brand palette rather than fighting it.

### Avoiding a Generic AI Look

- Start from real photos, real locations, real screenshots, or specific art direction whenever possible.
- Use concrete photographic language: lens, lighting, material, environment, camera angle, negative space.
- Avoid vague words like “futuristic,” “viral,” or “premium” unless you define what they mean visually.
- Do not let AI generate final text. Use Canva/editor text layers.
- Keep one strong idea per asset. Do not fill the composition with decorative clutter.

### Maintaining Realism

- Check hands, faces, logos, small UI details, perspective, shadows, and reflections.
- Compare the final asset against real client materials.
- Prefer subtle enhancement over dramatic transformation when trust matters.
- If the result looks like a template, return to the art direction and add client-specific constraints.

## G. Reusable Prompt System

Use these prompts as starting points. Replace bracketed fields with client-specific context.

### Improve a Website Screenshot

```text
Create an art direction prompt to enhance this website screenshot for [client].
Goal: make it feel polished, realistic, and campaign-ready without changing the core UI.
Use a [device/browser] presentation, [brand colors], subtle depth, clean lighting, and enough negative space for headline text.
Preserve the layout and avoid inventing new claims, logos, or unreadable fake text.
Final text will be added later in Canva.
```

### Create a Realistic Background for a Static Piece

```text
Write a prompt for a realistic photographic background for [client] targeting [audience].
The asset supports this message: [hook/headline].
Style: [editorial / modern / warm / technical / premium], real-world setting, believable lighting, clean composition, negative space for text.
Use colors related to [palette]. Avoid generic stock imagery, fake UI, excessive decoration, and AI-looking perfection.
```

### Improve a Mockup

```text
Create a Magnific-ready enhancement direction for this [website/app/product] mockup.
Keep the actual product/screenshot recognizable. Improve lighting, depth, texture, and presentation quality.
Make it suitable for [format/platform] and leave space for [headline/CTA].
Do not alter important UI details, numbers, claims, or brand marks.
```

### Reinforce an Editorial Look

```text
Define an editorial visual direction for [client] using [real asset or base image].
The mood should feel [modern / premium / close / sharp / calm], not corporate-generic.
Use strong contrast, restrained composition, intentional negative space, and brand-colored accents.
The final composition will add typography and overlays manually in Canva.
```

### Prepare a Visual for a Carousel

```text
Build a carousel visual system for [client] about [topic].
Slide 1 hook: [hook].
Slides: [number of slides].
Create a consistent background/overlay system, headline hierarchy, image treatment, and color rhythm.
Specify which slides need screenshots, mockups, real photos, icons, or simple text-led layouts.
Avoid decorative clutter and keep each slide readable on mobile.
```

### Adapt a Visual for an Ad

```text
Adapt this visual concept into a paid ad image for [client] promoting [offer].
Prioritize fast comprehension, high contrast, clear headline, visible CTA, and credibility.
Create [number] variants with different hooks or emphasis: [pain / outcome / proof / offer].
Keep final text editable in Canva and avoid AI-generated text inside the image.
```

## H. Quality Checklist

Before approving the asset, check:

- **Legibility:** Can the headline be read quickly on mobile?
- **Visual coherence:** Do image, colors, type, and layout feel intentionally connected?
- **Message clarity:** Is the main idea obvious without needing extra explanation?
- **Hierarchy:** Is there one clear visual and textual priority?
- **Realism:** Do lighting, perspective, screenshots, faces, hands, and textures hold up?
- **Brand consistency:** Does the asset feel like this client, not a generic template?
- **Campaign utility:** For paid assets, is the offer, audience, CTA, or proof clear enough to test?
- **Organic utility:** For organic assets, does it create curiosity, usefulness, or recognition?
- **Non-generic AI feel:** Would a viewer believe this came from the client’s own visual system?

## I. Adapting the Framework to Other Clients

To reuse this system for another client, change:

- **Palette:** Pull colors from the logo, website, product UI, or existing brand book.
- **Tone:** Decide whether the client should feel technical, warm, editorial, local, luxury, playful, direct, or founder-led.
- **Typography:** Define headline and body fonts or the closest available Canva equivalents.
- **Business type:** Adjust settings, props, proof, screenshots, and visual metaphors to the client’s actual category.
- **Asset base:** Use real photos, screenshots, product visuals, physical locations, or founder/team images when available.
- **Campaign objective:** Change the composition based on whether the piece is for awareness, conversion, retargeting, launch, nurture, or education.
- **Channel:** Adapt density and hierarchy for Instagram, LinkedIn, TikTok/Reels covers, YouTube thumbnails, Meta ads, or website visuals.

Keep the same operating logic: message first, real assets second, enhancement third, editable composition fourth, export and review last.
